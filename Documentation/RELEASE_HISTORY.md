# Release history

The steps that took this project from a private working name to a public open-source project, in order. Decisions are in `Documentation/Architecture/DECISIONS.md`; this page is the timeline. A row says "not yet" until the step is done.

| # | Milestone | Date | Result | Record |
|---|---|---|---|---|
| 1 | Name checked | 2026-11-12 | No match for "FlightSim Aide" on the web, Google Play, GitHub or the Apple App Store. US trademark search (USPTO): nothing close. | D-80 |
| 2 | Name chosen | 2026-11-12 | FlightSim Aide. The earlier working name was dropped because another app uses a near-identical name. | D-80 |
| 3 | Domain registered | 2026-11-12 | `flightsimaide.com` (the `.net`, `.app` and `.dev` were free and not bought). | D-80 |
| 4 | GitHub organisation created | 2026-11-12 | `github.com/flightsimaide` | D-80 |
| 5 | Code licence | 2026-11-12 (date of the `LICENSE` file) | MIT. | `LICENSE` |
| 6 | Content licence | open | CC-BY-4.0 proposed for docs and checklists; not yet decided. | - |
| 7 | Trademark and brand wording | 2026-11-13 (date of the notices file) | "For X-Plane" as a description only, no simulator logos, an unaffiliated and sim-only disclaimer. | `README.md`, `THIRD_PARTY_NOTICES.md` |
| 8 | Public-release audit | 2026-11-13 | Clean, with one open decision on the private test IP addresses. | `tools/audit_public_release.sh` |
| 9 | Moved to the new repository | 2026-11-13 | Package `flightsim_aide`, plugin 0.1.0, tests and live contract green. | - |
